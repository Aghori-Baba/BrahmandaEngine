# Brahmanda Engine

=====Licensed under MIT License (see LICENSE file)=====

This is an EXPERIMENTAL Engine being developed for learning and internal use. APIs can and will change without notice. Systems may break, change or disappear as development progresses. This project is NOT RECOMMENDED FOR PRODUCTION USE. Use it at your own risk (as per the MIT License).

This is a personal project intended to explore and learn game engine development from scratch. Built from the ground up, this engine serves as a sandbox for experimenting with rendering, physics, and game logic.

Current stack uses CMake, Raylib, Dear ImGui and spdlog. The target for now is to make a simple engine and develop a game using this stack and publish it.
